SSH Manager
Утилита для управления SSH-подключениями к удалённым серверам.

Описание
ssh_manager — это инструмент командной строки, который упрощает работу с SSH-соединениями. Он позволяет централизованно управлять конфигурациями подключений к серверам, избавляя от необходимости запоминать IP-адреса, имена пользователей и параметры доступа.

Возможности
Централизованное хранение конфигураций SSH-подключений в удобном формате.

Быстрое подключение к серверу по короткому имени или алиасу.

Поддержка стандартных SSH-параметров (порт, пользователь, ключ).

Удобный интерфейс командной строки.
